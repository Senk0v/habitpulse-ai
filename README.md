# HabitPulse AI — AI-трекер привычек с поведенческой аналитикой

Интерактивный MVP-прототип B2C-приложения для формирования устойчивых привычек, объединяющий трекинг стриков, 14-дневную тепловую карту активности и встроенного AI-коуча на базе Gemini API.

**Живое демо:** https://senk0v.github.io/habitpulse-ai/

---

## Продуктовая гипотеза и решаемая проблема

**Проблема:** Около 75% пользователей классических трекеров привычек бросают приложение в первые 14 дней. Основная причина — эффект «сломанного стрика»: пропустив один день из-за высокой нагрузки или выходных, пользователь теряет мотивацию и уходит в отток.

**Решение (MVP):** Внедрить предиктивную поведенческую аналитику и AI-коуча, который анализирует паттерны выполнения, заранее подсвечивает дни просадки (например, пятницу и выходные) и предлагает адаптацию нагрузки до того, как пользователь забросит привычку.

## Ключевые продуктовые метрики и Unit-экономика

* **North Star Metric:** WAHC (Weekly Active Habit Completions) — количество подтвержденных целевых действий на активного пользователя в неделю.
* **Aha-moment:** Получение первого персонального AI-инсайта после 3 дней регулярного трекинга (момент, когда система находит первую закономерность в поведении).
* **Целевой Retention (Day 14):** рост с базовых 22% до 32% за счет сценариев защиты стрика.

## Функциональность MVP

* **Управление привычками:** создание, фильтрация по категориям (Здоровье, Обучение, Продуктивность, Финансы), автоматический подсчет текущего и лучшего стриков, сохранение состояния в `localStorage`.
* **14-дневная тепловая карта (Heatmap):** визуализация стабильности выполнения привычек с детализацией по каждому дню.
* **AI Coach & Insights:** модуль поведенческой диагностики (поиск узких мест в расписании и генерация рекомендаций по новым привычкам).
* **Product Passport:** встроенная в интерфейс панель с описанием продуктовой гипотезы, метрик и экономики проекта.

## Стек и процесс разработки

* **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript (Single-Page Architecture без тяжелых зависимостей для мгновенной загрузки).
* **AI & Prototyping:** спроектировано и собрано с использованием вайбкодинга (Cursor, LLM-агенты) и интеграцией Gemini API.
* **Хостинг:** GitHub Pages.
